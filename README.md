# 航拍影院 · Aerial Cinema

<img src="Resources/IconSource.png" width="144" alt="航拍影院图标">

[下载 Mac 应用](https://github.com/channelchoi/aerial-cinema/releases/latest) · [使用说明](使用说明.md) · [MIT 代码许可](LICENSE)

A tiny native macOS app for fullscreen, synchronized playback of locally downloaded Apple aerial videos. Hold Esc for 5 seconds to exit.

双击“应用程序”中的 **航拍影院**，即可在所有显示器上全屏播放系统已下载的航拍视频。

- **退出**：持续按住 Esc 满 5 秒；地点文字在 0.25 秒内淡出、小圆环同时淡入，填满后退出。提前松手会取消，圆环淡出、地点淡入，并清零计时。5 秒从按下按键开始计算。
- **地点**：左下角常驻两行小字，上方为中文“城市 · 国家”，下方为英文。中文 12 点、英文 10 点，距左边和下边各 24 点，白色细阴影、无底板。切换视频时同步更新地点。
- **播放**：静音、等比例铺满屏幕。每轮随机排列，轮内不重复；一轮播完继续循环。
- **新增视频**：在 macOS 系统设置中下载更多航拍视频。影院每 30 秒检查一次，新增文件经稳定性和格式检查后自动加入，不打断当前视频。通常需 30—60 秒。
- **多个屏幕**：所有屏幕播放同一视频与进度，按各屏幕比例裁切。没有播放控件、标题、鼠标、菜单栏或程序坞。按住 Esc 时，仅在左下角显示直径 24 点的细圆环，没有底板或文字。
- **普通按键**：短按 Esc、Command+Q、Command+W、空格和鼠标点击不停止播放。Command+Tab 可切换应用；系统强制退出仍可使用。
- **重开**：应用运行时再次打开只激活原实例，不重复创建播放器。

视频直接读取，不复制或修改系统文件。当前支持的目录：

```
~/Library/Application Support/com.apple.wallpaper/aerials/videos
/Library/Application Support/com.apple.idleassetsd/Customer/4KSDR240FPS
```

未下载完成、损坏或无法解码的文件不会阻断整个列表；本轮播放失败的文件会暂时排除，文件变化后重新检查。全部视频不可用时，先恢复桌面，再显示简短说明。

播放期间阻止系统因闲置自动熄屏；正常退出会释放该限制，并恢复鼠标和系统栏。没有开机启动、设置页面、联网下载或后台常驻服务。

## 地点识别

使用系统航拍目录中的视频标识匹配地点，不依赖播放顺序。目前内置纽约、旧金山、洛杉矶、伦敦、迪拜与香港的中英文城市和国家名称，同一城市的新镜头可以自动匹配；未识别的视频显示“地点未知 / Location unknown”，继续正常播放。

按住 Esc 期间切换视频不会中断计时，取消后恢复的是新视频地点。快速反复按键会从当前透明度平滑反向过渡。

## 重新构建

需要 Apple Silicon Mac、macOS 14 或以上及 Xcode Command Line Tools。当前安装版在本机 macOS 27.2 测试。

在终端进入本目录，运行：

```sh
./build.sh
```

生成的应用位于 `build/航拍影院.app`，使用本机临时签名。构建不会自动覆盖已经安装的应用。

`./test.sh` 运行无需视频素材的核心测试。`./test.sh --media` 进一步检查本机视频和动态入库，需要已经下载航拍视频，并安装 `ffmpeg` 与 Python 3，仅测试工具使用它们，正式应用不依赖它们。

`./build.sh --qa` 生成独立的测试版。测试版每段预览 5 秒，并在 3 分钟后自动结束，便于快速验证轮播。可通过 `AERIAL_QA_DIR`、`AERIAL_QA_LOG`、`AERIAL_QA_CLIP_SECONDS`、`AERIAL_QA_TIMEOUT` 环境变量调整测试素材和时长。测试日志默认写入系统临时目录中的 `aerial-cinema-qa.log`，正式版不包含这些测试入口或运行时日志。

## 为什么系统显示 11 张，程序里可能更少？

系统设置中的“轮换显示 11 张航拍”表示所选轮换组包含 11 个目录项目，不表示 11 个视频都已完成下载。程序只播放真正保存到本机且可以读取的视频。完成更多下载后会自动加入。

## 下载与首次打开

在 GitHub Releases 下载 `.zip`，解压后将“航拍影院.app”放入“应用程序”即可。当前二进制适用于 Apple Silicon；本地构建需要 Xcode Command Line Tools，不需要完整 Xcode。

发布包使用临时签名，未经过 Apple 公证。下载后 macOS 可能要求通过“系统设置 → 隐私与安全性”手动允许首次打开。

## 已验证与限制

1.1.0 验证了 11 个原始视频的双语地点、双屏快速切换、文字与圆环交叉淡化、快速反复按键、长按期间切换视频后取消并显示新地点。此前也已验证双屏播放、十一个原始视频的快速切换、短片自然结束后的循环、长按退出和提前松手取消，以及新增／删除／损坏文件的处理。播放进度通过共同系统时钟安排，并对超过 60 毫秒的偏差重新对齐；不同刷新率显示器不保证逐帧完全一致。

显示器热插拔和休眠唤醒有处理逻辑；尚未覆盖所有显示器、所有 macOS 版本和所有视频编码组合。
